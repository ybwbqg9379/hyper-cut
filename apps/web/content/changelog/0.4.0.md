Welcome to HyperCut 0.4.0. This release marks a significant milestone in our project's journey, focusing on a complete branding overhaul and deep architectural synchronization with the core rendering engine.

### 🌟 Branding Hardening

We have successfully purged all traces of generic project tags and synchronized the entire interface with the **HyperCut** identity:
- **Global Brand Identity**: Replaced all user-facing strings with HyperCut branding across the entire application.
- **Premium UI Restoration**: Restored HyperCut's signature premium export button with dynamic gradients and micro-animations.
- **Domain Alignment**: Updated all internal and documentation links to point to the `hypercut.app` ecosystem.
- **Logo Integrity**: Fixed the brand logo resolution in the editor header and aligned project naming conventions.

### ⚙️ Architectural Synchronization

Integrated the latest rendering pipeline and stabilized the local development environment:
- **Bun Ecosystem Migration**: Fully transitioned the project to Bun for dependency management, resolving library conflicts and significantly speeding up installation.
- **Rust/Wasm Engine Sync**: Linked the local Rust/Wasm rendering core (`opencut-wasm`) explicitly via TypeScript path mappings, ensuring high-performance video processing.
- **Dependency Audit**: Resolved the "Double React" conflict and stabilized the transcription service's ONNX runtime dependencies.

### 🛠️ UI/UX Improvements & Refinement

- **B2B Asset Focus**: Purged redundant non-B2B tabs (Filters, Effects, etc.) from the assets panel to maintain a professional, focused editing experience.
- **Hydration Resilience**: Fixed nested button warnings in the preview toolbar by implementing the Radix UI `asChild` pattern.
- **Menu Simplification**: Streamlined the project dropdown by removing deprecated help and documentation links.
- **Code Quality**: Achieved a 100% clean lint state (Biome) and verified the full production build pipeline.

Thank you for being part of the HyperCut journey!
